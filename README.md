# Stackday

Личный трекер IT-практики: цели на день и месяц, чтение системного дизайна и алгоритмов, повторение в выходные, календарь, результаты занятий и достижения.

Адрес GitHub Pages: **https://glec1er.github.io/stack_day/**.

## Твой прогресс

План, заметки, отметки и XP сохраняются в браузере. Они не отправляются в этот публичный репозиторий. GitHub Pages публикует интерфейс и не предоставляет облачную синхронизацию между устройствами.

У HTML-файла, прежнего сайта и GitHub Pages разные копии данных. Чтобы перенести свой план:

1. Открой прежний HTML-файл в том браузере, где отмечал занятия.
2. Выбери **Копия плана → Скачать мой план**.
3. На GitHub Pages выбери **Копия плана → Восстановить из файла**.
4. Проверь предварительный просмотр и нажми **Восстановить план**.

JSON переносит цели, шаги, записи, выполнения и прогресс. Периодически сохраняй резервный файл; локальная история также хранит последние изменения. Не добавляй личные JSON-копии в репозиторий.

## Запуск и проверка

Нужен Node.js 24 или новее. Сторонних зависимостей нет.

```sh
npm test
npm run build
python3 -m http.server 8000 --directory dist
```

Открой http://localhost:8000. Сборка создаёт автономный `dist/index.html`; его можно сохранить как отдельный HTML-файл. Сборка не меняет прежний `my-focus.html` или его браузерные данные.

## Публикация

В **Settings → Pages → Build and deployment → Source** выбери **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет все тесты, собирает страницу и публикует её после изменений `main`. Для pull request выполняются проверки без публикации. Запуск вручную доступен во вкладке Actions.

## Исходники

- `page.html`, `styles.css` — разметка и оформление.
- `app.js` — интерфейс и действия пользователя.
- `model.js`, `learning-model.js`, `control-model.js` — расписание, обучение и учёт прогресса.
- `storage.js`, `sync.js` — сохранение, резервирование и поддержка прежнего облачного размещения.
- `voice-*.js` — диктовка плана и результата, если браузер поддерживает распознавание речи.
- `*-ui.js` — формы, календарь, таймер и достижения.
- `build.mjs` — статическая сборка для Pages.
- `tests/` — проверки поведения, хранения и сборки.
- `worker.mjs`, `drizzle/` — исходники прежнего серверного API. На GitHub Pages этот API не запускается.
